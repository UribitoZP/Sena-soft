Código Fuente: ErrorUtil y DatabaseException

Manejo centralizado de errores de base de datos con notificaciones visuales al usuario.

DatabaseException

RuntimeException que envuelve SQLException para propagar errores de base de datos sin modificar las firmas de los métodos DAO.

public class DatabaseException extends RuntimeException {
    private final String contexto;

    public DatabaseException(String contexto, SQLException causa) {
        super("Error en " + contexto + ": " + causa.getMessage(), causa);
        this.contexto = contexto;
    }

    public String getContexto() {
        return contexto;
    }
}

¿Por qué RuntimeException?

Para no obligar a todos los llamadores de los DAOs a declarar throws SQLException. La excepción se propaga hasta la capa de UI o REST, donde se captura y se muestra al usuario.

ErrorUtil

Helper estático que muestra un JOptionPane con el error, permitiendo al usuario saber qué falló sin necesidad de revisar la consola.

public class ErrorUtil {
    public static void mostrarError(Component padre, String operacion, DatabaseException e) {
        String msg = "Ocurrió un error al " + operacion + ".\n\n" +
                      "Detalle: " + e.getMessage();
        JOptionPane.showMessageDialog(
            padre instanceof JFrame ? (JFrame) padre
                : (JFrame) SwingUtilities.getWindowAncestor(padre),
            msg,
            "Error de Base de Datos",
            JOptionPane.ERROR_MESSAGE
        );
        e.printStackTrace();
    }
}

¿Por qué no System.err.println?

Antes los errores solo se imprimían en consola. El recepcionista no veía la consola, así que los errores pasaban desapercibidos. Ahora un JOptionPane le informa inmediatamente.

Manejador global en ApplicationMain

Además, ApplicationMain registra un manejador de excepciones no capturadas en el EDT:

SwingUtilities.invokeLater(() -> {
            // ...
        Thread.setDefaultUncaughtExceptionHandler((t, e) -> {
            JOptionPane.showMessageDialog(null,
                "Error inesperado: " + e.getMessage(),
                "Error del sistema", JOptionPane.ERROR_MESSAGE);
        });
    });
