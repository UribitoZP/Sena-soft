Código Fuente: PasswordUtil

Hash de contraseñas con PBKDF2 sin dependencias externas.

Propósito

Aplicar PBKDF2WithHmacSHA256 con 600.000 iteraciones y sal aleatoria de 16 bytes para almacenar contraseñas de forma segura.

Código completo

public class PasswordUtil {
    private static final String ALGORITHM = "PBKDF2WithHmacSHA256";
    private static final int ITERATIONS = 600_000;
    private static final int KEY_LENGTH = 256;
    private static final int SALT_LENGTH = 16;

    public static String hash(String password) {
        byte[] salt = SecureRandom.getSeed(SALT_LENGTH);
        SecretKeyFactory skf = SecretKeyFactory.getInstance(ALGORITHM);
        PBEKeySpec spec = new PBEKeySpec(password.toCharArray(), salt, ITERATIONS, KEY_LENGTH);
        byte[] hash = skf.generateSecret(spec).getEncoded();
        return Base64.getEncoder().encodeToString(salt) + ":" + Base64.getEncoder().encodeToString(hash);
    }

    public static boolean verificar(String password, String hashAlmacenado) {
        String[] partes = hashAlmacenado.split(":");
        byte[] salt = Base64.getDecoder().decode(partes[0]);
        byte[] hashOriginal = Base64.getDecoder().decode(partes[1]);
        SecretKeyFactory skf = SecretKeyFactory.getInstance(ALGORITHM);
        PBEKeySpec spec = new PBEKeySpec(password.toCharArray(), salt, ITERATIONS, KEY_LENGTH);
        byte[] hashCalculado = skf.generateSecret(spec).getEncoded();
        return MessageDigest.isEqual(hashOriginal, hashCalculado);
    }
}

Explicación

hash(String password)

Genera una sal aleatoria de 16 bytes, crea un SecretKeyFactory con el algoritmo PBKDF2, configura la especificación con la contraseña, sal, iteraciones y longitud de clave, genera el hash y lo codifica en Base64 junto con la sal separados por dos puntos.

verificar(String password, String hashAlmacenado)

Divide el hash almacenado en sal y hash, recalcula el hash con la contraseña proporcionada y la misma sal, y compara usando MessageDigest.isEqual() para evitar timing attacks.

¿Por qué 600.000 iteraciones?

OWASP recomienda al menos 600.000 iteraciones para PBKDF2-HMAC-SHA256 en 2023. Es un balance entre seguridad y rendimiento.

Integración

Usado en UsuarioDAO.autenticar() y UsuarioDAO.crear(). SchemaManager v7 migra contraseñas planas a hash automáticamente.
