Guía de Ejecución

Pasos necesarios para poner en marcha el aplicativo de escritorio.

1. Requisitos del Sistema

Para asegurar el correcto funcionamiento del software, su entorno de desarrollo debe contar con:

  • JDK 17+: El proyecto utiliza características de Java 17.
  • MySQL / MariaDB: Motor de base de datos para persistencia.
  • Bibliotecas en /lib: 
    /lib
└── jcalendar-1.4.jar  // Gestión de fechas visual

2. Instalación y Compilación

Si no utiliza un IDE (como IntelliJ o NetBeans), puede compilar y ejecutar el proyecto manualmente desde la terminal usando los siguientes comandos (estando en la raíz de "Aplicativo Escritorio"):

# 1. Crear carpeta para binarios
mkdir bin

# 2. Compilar el proyecto incluyendo librerías
javac -cp ".;lib/*" -d bin -sourcepath src src/com/santaana/main/ApplicationMain.java

# 3. Ejecutar la aplicación
java -cp "bin;lib/*" com.santaana.main.ApplicationMain

Automatización: Puede utilizar el archivo run.bat incluido en la carpeta raíz del aplicativo para automatizar este proceso en sistemas Windows.

3. Configuración de Base de Datos

  1. Importar el esquema SQL (ubicado en la carpeta de base de datos).
  2. Verificar que el puerto 3306 esté abierto.

Arquitectura del Sistema

Diseño Modular Orientada a Roles (Java Swing)

1. Estructura de Paquetes

Hemos implementado una estructura basada en el principio de responsabilidad única:

com.santaana
├── controller    // Lógica de negocio y control
├── main          // Punto de entrada (ApplicationMain)
├── util          // Utilidades (ThemeManager, etc)
└── view          // Interfaces de usuario (JFrame, JPanel)

Ventaja: Permite que los desarrolladores trabajen en módulos independientes sin generar conflictos.

2. Orquestación de Vistas

El sistema utiliza una ventana principal (HomeFrame) que actúa como un contenedor dinámico según el perfil.

Componente Responsabilidad Estado
TableroFrame Dashboard principal para Administradores. Optimizado
ReservaFrame Gestión operativa de huéspedes. Optimizado

3. Personalización: Modo Oscuro "Dark Blue"

Se ha implementado un sistema robusto de temas para alternar entre un modo claro y un modo oscuro basado en una paleta de azul profundo.
