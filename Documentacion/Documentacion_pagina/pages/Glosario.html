DOCUMENTACIÓN

Glosario del Sistema

Conceptos técnicos y términos utilizados en el sistema de gestión hotelera.

Nota: Este glosario reúne definiciones técnicas, conceptos de seguridad, funcionalidades y componentes usados dentro del sistema hotelero.

AES-256

Seguridad

Algoritmo de cifrado avanzado utilizado para proteger backups y datos sensibles. Garantiza que la información sea ilegible sin la clave correcta.

Cifrado avanzado Encriptación AES Seguridad de datos

Backup

Sistema

Copia de seguridad de los datos del sistema, almacenada en ubicaciones seguras (ej: C:\Backups\Hotel).

Copia de seguridad Respaldo Backup automático

Backup de emergencia

Seguridad

Copia automática activada tras 24 horas de sesión continua o ante fallos críticos, cifrada con AES-256.

Respaldo crítico Backup automático Recuperación de datos

Check-in

Huéspedes

Proceso de registro de entrada de un huésped, asignando una habitación y capturando datos personales.

Registro de entrada Ingreso Recepción

Check-out

Facturación

Proceso de salida del huésped, incluyendo cálculo de costos, generación de factura PDF y liberación de la habitación.

Salida Finalización de estadía Pago

CRUD

Desarrollo

Operaciones básicas de gestión de datos: Crear, Leer, Actualizar y Eliminar.

Gestión de datos Operaciones básicas Mantenimiento

DB

Base de datos

Base de datos SQLite donde se almacena toda la información del sistema.

Base de datos SQLite Repositorio

Hash (bcrypt)

Seguridad

Algoritmo de encriptación unidireccional para contraseñas, con salt y cost factor de 12 iteraciones.

Hashing bcrypt Cifrado de contraseñas

ID

Sistema

Identificador único asignado a huéspedes, habitaciones y facturas para su trazabilidad.

Identificador Código único Clave

Interfaz adaptativa

UI

Diseño de interfaz que muestra u oculta funciones según el rol del usuario.

UI adaptable Interfaz dinámica Diseño responsivo

Login

Acceso

Acceso seguro al sistema mediante autenticación de dos factores.

Inicio de sesión Autenticación Ingreso seguro

Modo claro/oscuro

UI

Tema visual intercambiable para mejorar la experiencia según las preferencias del usuario.

Tema visual Dark mode Light mode

PDF

Documentos

Formato de documento utilizado para facturas con estructura profesional y código QR.

Documento digital Factura PDF Portable Document Format

Roles

Usuarios

Perfiles de usuario: Administrador y Recepcionista, cada uno con permisos específicos.

Permisos Perfiles Niveles de acceso
