Solución de Problemas Comunes

Errores frecuentes, sus causas y cómo resolverlos.

Error Causa Solución
java: command not found JDK no instalado o no en PATH Instalar JDK 17+ y agregar JAVA_HOME a las variables de entorno
NoClassDefFoundError: org/slf4j/LoggerFactory Faltan los JARs de SLF4J en el classpath Verificar que slf4j-api-1.7.36.jar y slf4j-nop-1.7.36.jar estén en /lib
[SQLITE_CONSTRAINT_CHECK] Valor inválido para una columna con restricción CHECK Verificar que el estado sea exactamente: Disponible, Ocupada, Limpieza o Mantenimiento
Puerto 8080 ocupado Otro proceso usa el puerto 8080 El servidor ahora usa HTTPS en puerto 8443. Si el error persiste, ejecutar netstat -ano | findstr :8443 y cerrar el proceso.
SSLHandshakeException en el móvil Certificado autofirmado no aceptado En Android, agregar la excepción de seguridad en el cliente HTTP o instalar el certificado como CA de confianza. Consultar la documentación del aplicativo móvil.
Keystore was tampered with Contraseña del keystore incorrecta o archivo corrupto Regenerar el keystore con keytool -genkeypair -alias santaana -keyalg RSA -keysize 2048 -keystore ssl/keystore.p12 -storetype PKCS12 -storepass sant@an@ -validity 365 -dname "CN=Hotel Santa Ana, OU=TI, O=Santa Ana, L=Bogota, C=CO"
Datos no se actualizan en pantalla El panel no se refresca después de una acción Usar el botón de recarga o cerrar y reabrir la sección. El sistema usa SwingUtilities.invokeLater() para refrescos seguros.
Database is locked Dos hilos intentan escribir en SQLite simultáneamente El método getConnection() es synchronized. Si el error persiste, verificar que no haya otro proceso usando el archivo santaana.db.
Base de datos creada en el Escritorio Ejecutaron run.bat desde un acceso directo con directorio de trabajo incorrecto La ruta ahora es absoluta. Eliminar el santaana.db del Escritorio y ejecutar desde la carpeta Aplicativo Escritorio/.
Habitaciones disponibles incorrectas Fecha con formato no ISO (dd/MM/yyyy) llegó a la consulta SQL DateUtil ahora fuerza el formato ISO. Si el error persiste, verificar que no haya llamadas directas a SimpleDateFormat con patrón incorrecto.
