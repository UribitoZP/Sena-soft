Código Fuente: AuthHandler

Maneja la autenticación de usuarios con rate limiting y generación de tokens.

Propósito

Procesa las solicitudes POST a /auth/login. Verifica credenciales contra la base de datos, aplica rate limiting por IP y genera un token UUID para el cliente autenticado.

Código completo

public class AuthHandler implements HttpHandler {
    private static final Map<String, int[]> intentos = new HashMap<>();
    private static final int MAX_INTENTOS = 5;
    private static final long BLOQUEO_MS = 30_000;

    @Override
    public void handle(HttpExchange exchange) throws IOException {
        if ("OPTIONS".equals(exchange.getRequestMethod())) {
            JsonUtil.enviarRespuesta(exchange, 204, "");
            return;
        }
        if (!"POST".equals(exchange.getRequestMethod())) {
            JsonUtil.enviarRespuesta(exchange, 405, "{\"error\":\"Método no permitido\"}");
            return;
        }

        String ip = exchange.getRemoteAddress().getAddress().getHostAddress();
        long ahora = System.currentTimeMillis();

        synchronized (intentos) {
            if (intentos.containsKey(ip)) {
                int[] datos = intentos.get(ip);
                if (datos[0] >= MAX_INTENTOS) {
                    if (ahora - datos[1] < BLOQUEO_MS) {
                        JsonUtil.enviarRespuesta(exchange, 429,
                            "{\"error\":\"Demasiados intentos. Espere 30 segundos.\"}");
                        return;
                    } else {
                        intentos.remove(ip);
                    }
                }
            }
        }

        String body = new String(exchange.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        String usuario = extraer(body, "usuario");
        String clave = extraer(body, "clave");

        UsuarioDAO dao = new UsuarioDAO();
        String token = null;
        try {
            int idUsuario = dao.autenticarSinRol(usuario, clave);
            if (idUsuario != -1) {
                synchronized (intentos) { intentos.remove(ip); }
                token = TokenManager.generar(usuario);
                String json = String.format(
                    "{\"token\":\"%s\",\"usuario\":\"%s\",\"rol\":\"%s\"}",
                    token, usuario, dao.buscarPorId(idUsuario).getRol());
                JsonUtil.enviarRespuesta(exchange, 200, json);
            } else {
                registrarIntento(ip);
                JsonUtil.enviarRespuesta(exchange, 401,
                    "{\"error\":\"Credenciales inválidas\"}");
            }
        } catch (DatabaseException e) {
            JsonUtil.enviarRespuesta(exchange, 500,
                "{\"error\":\"Error interno del servidor\"}");
        }
    }

    private synchronized void registrarIntento(String ip) {
        intentos.putIfAbsent(ip, new int[]{0, (int) System.currentTimeMillis()});
        intentos.get(ip)[0]++;
    }

    private String extraer(String json, String campo) {
        String busca = "\"" + campo + "\":\"";
        int inicio = json.indexOf(busca) + busca.length();
        int fin = json.indexOf("\"", inicio);
        return fin == -1 || inicio < busca.length() ? "" : json.substring(inicio, fin);
    }
}

Explicación

Rate limiting

El mapa intentos almacena por IP el contador de fallos y el timestamp del primer intento. Si se superan 5 intentos fallidos dentro de 30 segundos, la IP es bloqueada temporalmente. El bloqueo usa synchronized para acceso thread-safe.

Flujo de autenticación

  1. Verifica que sea método POST (responde 405 si no).
  2. Verifica rate limiting (responde 429 si bloqueado).
  3. Lee el body JSON y extrae usuario/clave.
  4. Llama a UsuarioDAO.autenticarSinRol() que verifica contra hash PBKDF2.
  5. Si es válido: remueve el contador de intentos, genera token UUID y retorna 200.
  6. Si no es válido: registra el intento fallido y retorna 401.
  7. Si hay error de BD: retorna 500 sin exponer detalles.

Parser JSON manual

El método extraer() busca el campo en el string JSON recorriendo caracteres. Es un enfoque frágil que se recomienda reemplazar por una librería como org.json o Gson en el futuro.
