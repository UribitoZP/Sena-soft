Código Fuente: TokenManager

Gestión de tokens UUID para autenticación de la API REST.

Propósito

Generar y validar tokens de acceso UUID para proteger los endpoints REST. Los tokens se almacenan en memoria y se eliminan al cerrar la aplicación.

Código completo

public class TokenManager {
    private static final Map<String, String> tokens = new ConcurrentHashMap<>();

    public static String generar(String usuario) {
        String token = UUID.randomUUID().toString();
        tokens.put(token, usuario);
        return token;
    }

    public static boolean verificar(String token) {
        return tokens.containsKey(token);
    }

    public static String obtenerUsuario(String token) {
        return tokens.get(token);
    }

    public static void remover(String token) {
        tokens.remove(token);
    }
}

Explicación

Map<String, String> tokens

ConcurrentHashMap para acceso thread-safe desde múltiples hilos (EDT y servidor REST).

generar(String usuario)

Crea un UUID aleatorio, lo asocia al nombre de usuario y lo retorna.

verificar(String token)

Retorna true si el token existe en el mapa (es válido).

obtenerUsuario(String token)

Retorna el nombre de usuario asociado al token.

Uso en AuthHandler

En POST /auth/login, si las credenciales son válidas, se genera un token con TokenManager.generar() y se retorna al cliente. En los demás endpoints, se extrae el token del header Authorization y se verifica con TokenManager.verificar().
