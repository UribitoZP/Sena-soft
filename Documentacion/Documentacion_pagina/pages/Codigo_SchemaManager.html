Código Fuente: SchemaManager

Sistema de migraciones automáticas para la base de datos SQLite usando PRAGMA user_version.

Propósito

Crear y migrar el esquema de la base de datos automáticamente al iniciar la aplicación. Cada versión incrementa el número de schema y ejecuta los cambios necesarios (CREATE TABLE, ALTER TABLE, migración de datos).

Estructura

El método principal aplicarMigraciones() lee la versión actual con PRAGMA user_version y ejecuta las migraciones pendientes en orden:

public class SchemaManager {

    public static void aplicarMigraciones() {
        try (Connection conn = DatabaseConnection.getConnection();
             Statement stmt = conn.createStatement()) {

            int versionActual = obtenerVersion(stmt);

            if (versionActual < 1) { migracionV1(stmt); versionActual = 1; }
            if (versionActual < 2) { migracionV2(stmt); versionActual = 2; }
            if (versionActual < 3) { migracionV3(stmt); versionActual = 3; }
            if (versionActual < 4) { migracionV4(stmt); versionActual = 4; }
            if (versionActual < 5) { migracionV5(stmt); versionActual = 5; }
            if (versionActual < 6) { migracionV6(stmt); versionActual = 6; }
            if (versionActual < 7) { migracionV7(stmt); versionActual = 7; }

            stmt.execute("PRAGMA user_version = " + versionActual);
            System.out.println("Esquema v" + versionActual + " listo.");
        } catch (SQLException e) {
            throw new DatabaseException("aplicar migraciones", e);
        }
    }

    private static int obtenerVersion(Statement stmt) throws SQLException {
        ResultSet rs = stmt.executeQuery("PRAGMA user_version");
        return rs.getInt(1);
    }
}

Migración v7 (passwords a hash)

private static void migracionV7(Statement stmt) throws SQLException {
    ResultSet rs = stmt.executeQuery(
        "SELECT id, clave FROM usuarios WHERE clave NOT LIKE '%:%'");
    while (rs.next()) {
        int id = rs.getInt("id");
        String clavePlana = rs.getString("clave");
        String hash = PasswordUtil.hash(clavePlana);
        stmt.execute("UPDATE usuarios SET clave = '" + hash + "' WHERE id = " + id);
    }
}

Detecta contraseñas sin el separador : (característico de PBKDF2 con Base64), las hashea y actualiza la base de datos.

SeedData

Después de las migraciones, SeedData verifica si la base está vacía y si es así inserta los datos iniciales con contraseñas ya hasheadas usando PasswordUtil.hash("1234").
