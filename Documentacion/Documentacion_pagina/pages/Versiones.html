Historial de Versiones

Registro detallado de actualizaciones y cambios en el sistema.

Versión Fecha Descripción de Cambios Responsable
v2.4.0 29/05/2026 Seguridad: Hash PBKDF2 con 600k iteraciones para contraseñas (PasswordUtil). Autenticación por token UUID en API REST (TokenManager). Rate limiting en login (5 intentos, bloqueo 30s).
Concurrencia: DatabaseConnection.getConnection() ahora es synchronized para evitar condiciones de carrera entre el EDT y el servidor REST.
Robustez: Ruta de base de datos calculada automáticamente desde la ubicación de la aplicación (ProtectionDomain), no depende del directorio de trabajo.
Manejo de errores: Nueva clase DatabaseException (RuntimeException) envuelve SQLException. ErrorUtil muestra JOptionPane con errores de BD en toda la UI.
Formato de fechas: DateUtil con DateTimeFormatter estricto (ISO yyyy-MM-dd HH:mm) reemplaza SimpleDateFormat en la capa de UI, garantizando consistencia con las consultas SQL.
TLS/SSL: Servidor REST migrado de HTTP (puerto 8080) a HTTPS (puerto 8443) con keystore autofirmado PKCS12.
Historial de login: Intentos fallidos registrados en historial con tipo "Login" desde API REST y UI de escritorio.
Sidebar scroll: Posición de scroll preservada al navegar entre páginas de documentación. 		Seguridad / Backend
v2.5.0 09/06/2026 CRUD completo de reservas:
Vista tabla: Nuevo modo "Listado" en ReservaPanel con JTable de todas las reservas, buscador por cliente/documento y doble clic para detalle/edición.
Confirmar reserva: Botón "Confirmar Reserva" en ReservaFrame conectado a ReservaDAO.crear() con creación automática de cliente y registro en historial.
Actualizar reserva: Nuevo método actualizar() en ReservaDAO que modifica fechas, horas, estado y anticipo. Botón "Actualizar Reserva" en el diálogo de detalle con formulario pre-rellenado.
Selección visual de habitación: Tarjetas de habitación en ReservaFrame con borde resaltado al seleccionar. 		Desarrollo UI / DB
v2.3.0 28/05/2026 Gestión de Usuarios funcional: CRUD completo (crear, editar, eliminar) desde la interfaz. Restricciones por rol: máximo 2 Administradores y 3 Recepcionistas. Nuevos campos telefono y correo en tabla usuarios. Corrección de autocompletado en reservas (limpia campos si documento no existe). Corrección de disponibilidad de habitaciones (excluye Ocupada y Mantenimiento). Desarrollo / DB
v2.2.0 24/05/2026 Normalización de Base de Datos en Tercera Forma Normal (3NF) con la nueva tabla clientes, eliminando redundancia en reservas. Integración de autocompletado en el formulario de reservaciones al digitar la identificación del cliente y adición de validaciones estrictas en la entrada de datos. Desarrollo / DB
v2.1.0 24/05/2026 Módulo de Reportes contables y estadísticas del hotel (ReportePanel, ReporteDAO). Funcionalidad de Cierre de Mes (CierreMes, CierreMesDAO) con persistencia en base de datos. Ajustes y validación mejorada para campos de anticipo en reservas (NuevaReservaDialog). Nuevas actas de trabajo en documentación. Desarrollo UI / DB
v2.0.0 06/04/2026 Integración completa app móvil ↔ escritorio: servidor REST Java en puerto 8080, ApiService Flutter, vistas conectadas a datos reales, restricción de acceso solo para administradores, campo de IP configurable en login móvil. Documentación técnica completa de ambos aplicativos. Desarrollo Full
v1.5.0 01/04/2026 Servidor REST integrado al escritorio: endpoints /auth/login, /habitaciones, /reservas, /stats. Autenticación sin rol para clientes móviles. Backend
v1.4.0 25/03/2026 Migración a SQLite embebido. Eliminación de dependencia MySQL. SchemaManager con migraciones automáticas (PRAGMA user_version). SeedData con usuarios y habitaciones de prueba. Checkout con flujo Ocupada → Limpieza → Disponible. Backend / DB
v1.3.2 17/03/2026 Reestructuración de guía de ejecución: comandos técnicos al principio y manual de compilación manual. Documentación
v1.3.1 17/03/2026 Actualización de documentación: Zoom en imágenes y requisitos técnicos. Documentación
v1.3.0 17/03/2026 Implementación de Modo Oscuro "Dark Blue" en aplicativo de escritorio con ThemeManager y ThemeListener. Desarrollo UI
v1.1.0 01/03/2026 Implementación de sistema de autenticación básica y diseño premium de interfaz de login. Diseño/Dev
v1.0.0 28/02/2026 Lanzamiento inicial de la estructura base del proyecto y documentación técnica (SRS, Casos de Uso). Arquitectura

Nota: Las versiones siguen el estándar de versionamiento semántico (SemVer).
